# Publication checklist

- [ ] Confirm permission to publish screenshots derived from an employer/team Workato environment.
- [ ] Review screenshots for tenant names, team/client names, IDs, URLs, and any sensitive metadata.
- [ ] Remove all access tokens, private keys, environment IDs, and customer/employee data.
- [ ] Do not publish a corporate recipe export or internal configuration without approval.
- [ ] Keep the original implementation and the independent dry-run reference distinct.
- [ ] Avoid claiming real production safety or live end-to-end tests without evidence.
- [ ] Confirm `screenshots/` paths render in GitHub before sending a recruiter the link.
